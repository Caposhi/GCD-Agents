# Start here

For a new AI engineering session:

1. Read root [`AGENTS.md`](../AGENTS.md).
2. Read [AI engineering handoff](AI_HANDOFF.md).
3. Read [Current status](STATUS.md).
4. Read [Roadmap](ROADMAP.md).
5. Follow only the specialized links needed for the authorized task.

Always inspect current source and mutable external state when relevant. Never infer production truth from stale prose or `render.yaml`, and never perform a write without authorization.
